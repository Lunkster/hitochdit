# Hit och Dit – Utforska Sverige

Webbapp för att logga besök i Sveriges naturreservat, nationalparker, världsarv, byggnadsminnen,
fornlämningar, kyrkor, fyrar, toppar, öar, sjöar och tätorter – på plats, med telefonens position.

**Appen:** https://hitochdit.xyz/

Det här repot innehåller bara gränssnittet som publiceras på webbplatsen (GitHub Pages).
Databas, skript och övrigt ligger inte här.
