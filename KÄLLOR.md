# Källor och licenser

Hit och Dit bygger på öppna data och öppen programvara. Tack till alla källor nedan.
Uppgifterna kan innehålla fel – det är alltid skyltningen och föreskrifterna på plats som gäller.

## Geodata
| Data | Källa | Licens / villkor |
| --- | --- | --- |
| Naturreservat, nationalparker, kulturreservat, naturminnen, Natura 2000 m.fl. | Naturvårdsverket (Skyddade områden, WMS/WFS) | Öppna data, CC0 |
| Världsarv, byggnadsminnen, slott och herrgårdar, fornlämningar, kyrkor, fyrar | Riksantikvarieämbetet (öppna geodata) | Öppna data enligt RAÄ:s villkor (oftast CC0) |
| Kommuner, län, socknar, höjddata (toppar) | Lantmäteriet | Öppna data, CC0 |
| Landskap | Lantmäteriets distriktskarta via Per Liedmans *svenska-landskap* | Enligt källans villkor |
| Tätorter | SCB, Tätorter 2023 | Öppna data, CC0 |
| Sjöar | SMHI, Svenskt vattenarkiv (Vattenytor 2016) | Öppna data enligt SMHI:s villkor |
| Öar och kompletterande kyrkor | © OpenStreetMap-bidragsgivare | ODbL 1.0 |
